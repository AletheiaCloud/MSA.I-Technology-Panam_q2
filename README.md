# PANAM_Q — Quantum Adaptive Self-Modeling Architecture

## Overview

PANAM_Q is an experimental, clean-room research architecture
investigating functional self-modeling, adaptive control,
and quantum-formalism-based memory mechanisms.

This project does NOT claim to create consciousness.

All mechanisms are treated as measurable functional properties.

## Core Mechanisms

- Density Matrix Memory (QuantumMemory)
- Epistemic Coherence
- Regime Shift Gate
- Quantum Decision Theory Shadow Planner
- Offline Replay / Sleep Consolidation
- MetaObserver
- SelfModel (functional estimate)
- WorldModel (EMA transition model)
